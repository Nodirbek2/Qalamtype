# Race car illustration assets (v3)

Created with built-in image generation, 20 October 2026. Eleven separate model illustrations replace the generic vector drawings. Tico used a real side-profile photograph as model reference; remaining models used explicit generation/year and body-detail prompts. Final production sprites are alpha-preserving 640px WebP exports (~28–37KB each).

Prompt template: One accurate factory-model car; semi-realistic cartoon illustration; strict side profile facing right; exactly two wheels; preserve real roofline, windows, lights, wheelbase and bumpers; transparent cutout; no scene, floor, shadow, text or people.

Models: red Daewoo Tico; cream VAZ 2107; green Nexia N100; silver Nexia N150; blue Spark M300; silver Lacetti J200; white second-generation Cobalt; blue Gentra; white ninth-generation Malibu; white 2023 Tahoe; black G63.

Wheel overlays reuse the corresponding sprite clipped to each rim. Rotation follows existing distance-based physics. All game prices, unlocks and performance remain unchanged.
